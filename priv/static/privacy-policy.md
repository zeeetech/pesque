# Privacy policy

This is a placeholder. Replace this file with your own policy before pointing a
real domain at this server.

## What this server stores

- The handle, DID, email address, and password hash of each account.
- Every record written to an account's repository, and the blocks those records
  are stored in.
- Blobs uploaded by an account.
- Firehose events, kept for a limited window so a consumer can replay them.

## Who can read it

Repository records and blobs are public: any repository they are served from is
anonymous and unlisted. Account credentials are not, and nothing in this
lexicon exposes them.
